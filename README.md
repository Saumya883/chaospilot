# ChaosPilot

AI-driven user chaos engineer for web apps. Give it a URL and a plain-English goal, and it tries to break your app like a real user would.

## Team
Saumya Mittal, Harshit Agarwal, Shrestha Sharma

## Structure
- `frontend/` Next.js + TypeScript
- `backend/` FastAPI

## Setup
1. Copy `.env.example` to `.env` and fill in your keys.
2. Frontend and backend setup instructions will be added here.
